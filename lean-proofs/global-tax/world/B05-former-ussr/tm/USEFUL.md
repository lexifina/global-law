# Turkmenistan: what this work is useful for (2026-11-20T03:05Z)

- Taxpayer: wages bear 10 % and no employee pension contribution; dividends 15 % (F1).
- Adviser: bank-deposit interest and pensions are not taxed (art. 187).
- Government: the deduction's amount is not in the Code; publishing it with the Code would make the tax checkable.
- Researcher: the Mejlis site publishes consolidated codes; the Ministry of Justice database needs a login.
