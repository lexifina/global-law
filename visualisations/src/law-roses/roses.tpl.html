Roses of the law

Twenty questions about when law is made, when it starts, how it changes and how long it lasts, each drawn as one rose per jurisdiction. The first rose in every grid, in a box, is the typical jurisdiction: the mean of the others' shares. Hover any petal for its numbers; each figure has a table underneath.

Local drafts, not published. Data: every law repository in global-law, read from git metadata (questions 1–10: visualisations/src/analysis11.json, round 11; questions 11–20: a fresh read of every local law repository's commits and the provision files each one adds, changes or deletes, 7 November 2026; Romania left out). Each act counts once, so France's 150,000 acts and Japan's 30 weigh the same in the typical rose. A jurisdiction is shown when it has at least 30 dated acts for that question.
